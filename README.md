# AeroCMS Redesign

Quick redesign mockup for **AeroCMS** (Aero Computer Management Solutions LLC) — MSP & HaaS provider out of Nampa, ID. Contracted client work for Joshua Keyes (Sales/Marketing/Onboarding role).

## What's here

- `BRIEF.md` — synthesis of the current site, the XMind strategy doc, and the gaps the redesign closes
- `index.html` — homepage
- `about.html` — story, values, full team, partners, offices
- `services.html` — 4-pillar overview + process + industries
- `services/it-business.html` — IT Business Solutions detail
- `services/security.html` — Security Solutions detail (vCISO, SIEM, MDR, EDR)
- `services/cloud.html` — Cloud Services detail (Azure, VMware, private)
- `services/hardware.html` — Hardware as a Service detail
- `plans.html` — Good/Better/Best/Enterprise + comparison table + Kaseya User Bundle + FAQs
- `resources.html` — Library: tools, guides, webinars, infographics, eBooks (~30 assets total)
- `news.html` — Blog index with featured post + 6 cards + category browse
- `contact.html` — Full form (with subject dropdown), 5 offices, social, FAQ
- `styles.css` — visual system (one stylesheet for all pages)
- `assets/logos/` — current brand mark + reference imagery
- `research/` — notes, captured copy, partner lists
